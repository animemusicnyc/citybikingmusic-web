# City Biking Site

Static site starter using Bun-compatible tooling, Vite, pnpm, Preact, TypeScript,
and SCSS.

## Requirements

- Node.js 20+
- pnpm 9+
- Bun 1.1+ if you want to run the same scripts with Bun

## Scripts

```sh
pnpm dev
pnpm build
pnpm preview
pnpm typecheck
```

Bun can run the same package scripts:

```sh
bun run dev
bun run build
```

The production site is emitted to `dist`.
